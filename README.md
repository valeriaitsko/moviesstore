**MoviesStore** is a **Django-based web application** that allows users to **browse, search, and manage a catalog of movies**. It includes features like **user authentication**, **movie categorization**, and full **CRUD functionality** for movies.

---## ✨ Features

- 🔐 **User registration**, **login**, and **logout**
- 🎥 **Add**, **update**, and **delete movies**
- 🗂️ **Categorize movies** by genre
- 📄 **Detailed movie pages**
- 🎨 **Responsive UI** with Bootstrap
- ⚙️ **Django Admin Panel** for content management
